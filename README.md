# AI Team Workbench · AI 团队工作台

**把表格数据、文本资料或日志交给 AI 团队，拿回一份有依据、可复核的报告。**

AI Team Workbench 是一个可以部署在自己 Linux 电脑或服务器上的网页工作台。你在项目群里提出需求，就能跟进任务、打开交付文件、查看审核结果。

[下载完整源码 ai-team-workbench-source.zip](./ai-team-workbench-source.zip?raw=1)

## 能做什么

| 场景 | 你可以交给团队做什么 |
| --- | --- |
| 数据质检 | 检查 CSV 或 TSV 缺少哪些列、哪些记录有空值或重复编号，按组计算样本数、均值、标准差等描述统计。 |
| 材料整理 | 从上传的笔记、数据字典或日志中提取依据，整理成 Markdown 报告或待办清单。 |
| 交付复核 | 让审核员打开实际报告，回查资料或复算数据，登记通过或说明哪里需要修改。 |

## 工作台的特点

- **成员独立执行，交接在群里可见。** 总管按需派活，研究员找依据，工程师分析和出稿，审核员复核。成员各有持续的 DeepSeek Harness 会话和角色记忆，在群里用 `@` 交接。读资料、复算和交付都有记录可查。
- **审核绑定到报告的具体版本。** 审核员须实际打开这一版并登记结论和依据，系统才会记录正式审核。待审核和要求修改有明确状态，修订稿另存，再由审核员复核。
- **一张任务卡就能看进展。** 「任务梳理」里能查看你的原始指令、成员进度和交付物。「报错」会标出出问题的成员和工具，处理过的报错也能追溯。中断、失败或待审核的任务可以继续处理。
- **多个项目可以长期并存。** 各项目分别保存群聊、成员会话、角色记忆、上传资料与报告。你可以随时切换项目，每个项目都能接着上次的记录做。

## 试一次报告复核

启动工作台后，新建项目并上传源码包里的 `examples/review-sample.csv`。这是一份合成表格，可以用来测试审核员能否发现错误。

> 请工程师保存一份初稿，暂写「T2 平均值为 48，测量日期完整」。请审核员打开初稿和原表，独立复算均值并检查日期，登记审核结论。有误就指出位置，让工程师另存修订版，再复核新版。

表里三条 T2 记录的平均值是 **44**，编号 `S03` 的日期为空。在任务梳理里可以对照两版报告、复算结果和审核意见，看看哪些错误被发现、修订稿有没有通过审核。

## 当前版本

当前为单用户工作台，任务全局排队，每次处理一轮，单轮上限为五分钟。支持上传 TXT、Markdown、CSV、TSV、JSON 和 LOG，单个文件最多 8 MB。资料工具使用只读权限，Markdown 产出另存。定时联网检索和消息推送需要另接自动化。

源码包包含网页、Node.js 服务、DeepSeek Harness 协作插件、依赖锁文件、安装脚本、测试和示例。解压后的 `ai-team-workbench/README.md` 提供完整说明。协作引擎使用固定版本的 DeepSeek Harness `0.2.2-rc.4`。

## 运行

需要 Linux、Node.js 24.9 或更新版本、npm、GNU coreutils 和 unzip。下载源码包后运行：

```bash
unzip ai-team-workbench-source.zip
cd ai-team-workbench
npm ci --ignore-scripts
npm run setup
npm start
```

首次配置请在终端设置网页口令并输入自己的 DeepSeek API Key，然后打开 `http://127.0.0.1:3358`。使用远程服务器时，可按源码包 README 建立 SSH 转发。需要常驻运行时，可以按 README 安装 systemd 用户服务。
